# 2.3. Needfinding

El proceso de Needfinding tiene como finalidad transformar la información obtenida en entrevistas y observación del dominio en necesidades concretas de usuario. Para este proyecto, el análisis se enfoca en comprender cómo los actores del transporte médico gestionan actualmente la conservación, ubicación, disponibilidad y entrega de productos sensibles.

## 2.3.1. User Personas

Se elaborará un User Persona por cada segmento objetivo identificado. Cada ficha deberá incluir información demográfica, contexto laboral, objetivos, frustraciones, comportamientos digitales, dispositivos de preferencia y necesidades vinculadas al traslado médico.

### User Persona 1: Personal médico de emergencia

Este arquetipo representa a profesionales que participan en la atención directa del paciente y requieren conocer rápidamente el estado de medicamentos, órganos o insumos transportados. Sus principales objetivos son asegurar la disponibilidad de productos médicos, reducir errores durante emergencias y actuar ante alertas críticas.

### User Persona 2: Operador logístico de salud

Este arquetipo representa a responsables de planificar y monitorear traslados médicos. Necesita coordinar rutas, supervisar ambulancias, anticipar demoras y responder ante incidentes relacionados con temperatura, ubicación o estado del vehículo.

### User Persona 3: Supervisor de institución de salud

Este arquetipo representa a responsables de validar entregas, revisar evidencia histórica y asegurar el cumplimiento de procedimientos internos. Requiere reportes confiables, registros de cadena de custodia y trazabilidad de cada traslado.

## 2.3.3. User Journey Mapping

Se elaborará un User Journey Map para cada User Persona, representando la experiencia actual antes de implementar la solución. Estos mapas permitirán identificar momentos de incertidumbre, puntos de dolor y oportunidades para mejorar la coordinación del transporte médico.

El journey del personal médico se centrará en la necesidad de recibir o utilizar productos médicos en condiciones seguras. El journey del operador logístico se enfocará en la planificación, seguimiento y reacción ante incidentes. El journey del supervisor institucional abordará la validación posterior del traslado y la revisión de evidencias.

## 2.3.4. Empathy Mapping

Los Empathy Maps permitirán sintetizar lo que cada User Persona dice, piensa, hace, escucha, ve, siente y necesita durante el proceso de transporte médico. Este análisis ayudará a identificar preocupaciones principales como pérdida de cadena de frío, falta de visibilidad, retrasos, escasez de información y necesidad de evidencia confiable.

Para el personal médico, se espera encontrar preocupación por la seguridad del paciente y la disponibilidad inmediata de insumos. Para el operador logístico, se espera identificar presión por coordinar múltiples variables operativas. Para el supervisor institucional, se espera reconocer la necesidad de control, cumplimiento y trazabilidad.
