# 2.5. Ubiquitous Language

El Ubiquitous Language define los términos principales del dominio para evitar ambigüedades entre el equipo de desarrollo y los actores del negocio. Los términos se presentan en inglés, con una definición en español orientada al contexto del transporte médico controlado.

| Term | Definición |
|---|---|
| Smart Medical Container | Contenedor equipado con sensores IoT para transportar productos médicos bajo condiciones controladas. |
| Medical Load | Conjunto de medicamentos, órganos, muestras biológicas o insumos médicos transportados en el contenedor. |
| Temperature Range | Intervalo mínimo y máximo de temperatura permitido para conservar adecuadamente la carga médica. |
| Cold Chain | Proceso que asegura la conservación de productos sensibles mediante control continuo de temperatura. |
| Stock Detection | Estimación de disponibilidad de productos transportados mediante sensores de peso u otros mecanismos de medición. |
| Traceability Record | Registro histórico de eventos, condiciones, ubicaciones y responsables asociados a un traslado médico. |
| Chain of Custody | Secuencia documentada de responsables que manipulan, trasladan o reciben la carga médica. |
| Medical Transport | Operación de traslado de productos médicos desde un origen hasta un destino autorizado. |
| Critical Alert | Notificación generada cuando se detecta una condición que puede comprometer la seguridad de la carga. |
| Estimated Time of Arrival | Tiempo aproximado de llegada calculado a partir de ubicación, ruta, velocidad y condiciones del vehículo. |
| Vehicle Fuel Level | Información sobre la cantidad de combustible disponible en la ambulancia o unidad de transporte. |
| Container Opening Event | Evento registrado cuando el contenedor es abierto durante una operación de traslado. |
| Emergency Medical Staff | Personal de salud que participa en la atención de emergencias y requiere acceso rápido a información crítica. |
| Medical Logistics Operator | Usuario responsable de coordinar, supervisar y controlar traslados médicos. |
| Delivery Confirmation | Registro que evidencia que la carga fue recibida en el destino correspondiente. |
| Incident | Situación inesperada durante el traslado, como demora, temperatura fuera de rango, bajo combustible o pérdida de conexión. |
